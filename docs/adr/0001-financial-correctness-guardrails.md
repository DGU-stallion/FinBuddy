# ADR-0001: 金融正确性护栏——营收冲击推演、硬编码真空期、L2 降级存证

**Status**: Accepted
**Date**: 2026-10-12

## Context

FinBuddy 的核心价值主张是"AI 定性 + 数学公式定量"，但在 grill-with-docs 盘问中发现 spec 存在三个会引发金融幻觉的默认假设：

1. 敏感性测算公式依赖"大客户营收占比 35%"，但扶摇/iFinD 均无该实时字段（前五大客户集中度仅见于年报，且非实时）。该数字本身是幻觉源。
2. "信息真空期"的判定交给 LLM 自由心证，违反题目"数据缺失不得静默生成正常结论"的红线。
3. L2 降级存证的数据来源、过期性未定义，可能用过期数据生成"看似正常"的结论。

## Decision

1. **营收冲击推演取代大客户砍单测算**：敏感性测算改为"营收整体下滑 X% → 净利润冲击"，公式 `ΔNetProfit = BaseRevenue × ΔRevenueDeclinePct × NetMargin × (1 - TaxRate)`（净利率取真实财报值）。不引入任何无法实时获取的推断参数。客户集中度问题归入【无法验证项】。
2. **信息真空期硬编码**：当 iFinD 公告检索返回空、工具调用失败或标的未收录时，网关层强制将该子问题归入【无法验证项】。LLM 只能描述该状态，不得翻案或脑补。
3. **L2 降级存证仅限预置案例**：本地预置中际旭创等 2-3 个演示案例的真实抓取数据（写死入代码），显著标注抓取日期与"非实时数据"警告。自由查询不走 L2，直接进入信息真空期声明。

## Consequences

### 正面
- 彻底消除"大客户占比"幻觉源，敏感性测算的所有输入参数均可追溯到真实财报字段。
- 信息真空期判定从"LLM 自由心证"变为"网关硬编码"，合规确定性 100%。
- L2 降级范围收窄到预置案例，自由查询不存在"用过期数据冒充正常结论"的风险。

### 负面 / 代价
- "大客户砍单"场景的测算精度下降（无法区分客户集中度），但这本来就是一个无法实时验证的变量，诚实优于精确。
- 预置案例数据需要定期手工更新，但作为演示用途可接受。

## 真实数据契约（真机验证 2026-10-12）

- 扶摇财务指标 `report` = `{yyyy}-{1|2|3|4}`（如 `2024-3` = 三季报）
- 扶摇利润表 `period` = `annual` | `quarterly`
- 扶摇返回净利率字段：`sale_net_interest_ratio`（中际旭创 2024Q3 = 22.36%）
- iFinD 公告检索必填 `time_start`/`time_end`（`YYYY-MM-DD`），返回语义检索片段

## 补充决策（grill 第二轮，2026-10-12）

4. **基准营收口径用 TTM 年化**：`BaseRevenue` 优先取最近四季滚动（TTM）年化营收；若扶摇无法直接拼出 TTM，降级为“最近单季 ×4”并在 UI 明确标注口径。不用季节性扭曲的“单季×4”作首选，不用过旧的“最近年报”。
5. **标的范围覆盖全 A 股**：靠扶摇标的检索把“名称/代码”解析为 thscode；解析失败明确告知“未识别标的”并走信息真空期诚实声明，不限死标的范围（避免被评委冷门股刁难时露怯）。
