# 05: 营收冲击推演引擎 + 预置案例 + 多轮上下文

**What to build:** 确定性敏感性测算闭环与产品化收尾。Agent 从财报工具提取的真实参数注入客户端公式引擎，用户拖动"营收整体下滑幅度"滑块时每帧重算净利润冲击；中际旭创预置案例一键出完整链路；多轮追问携带结构化结论摘要（见 ADR-0001 决策 1、4 与 spec 交互决策）。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 客户端公式引擎：`ΔNetProfit = BaseRevenue × ΔRevenueDeclinePct × NetMargin × (1 - TaxRate)`，纯前端 React State 计算，零 LLM 参与
- [ ] 参数注入：Agent 从网关 `lookupFinancialReport` 取得的 `BaseRevenue`(TTM)、`NetMargin`、`TaxRate` 注入公式引擎，并在 UI 标注口径与时点
- [ ] 滑块交互：拖动 `ΔRevenueDeclinePct`（5%~30%）时每帧重算，Network 面板不产生 LLM 请求；阈值区间随数值联动变色
- [ ] 模型简化声明：测算卡片显式展示"线性一阶近似"局限（无固定成本摊薄、无产能再分配），并声明不构成精确盈利预测
- [ ] 中际旭创预置案例：一键触发完整链路（三栏证据 + 存证抽屉 + 测算卡片），数据经真机验证
- [ ] 备选预置案例 1 个（数据同样需真机验证可用）
- [ ] 多轮上下文：追问时网关维护"本轮标的 + 已确认事实"的结构化结论摘要传给下一轮，不传完整对话历史
- [ ] 计算确定性测试：固定参数下断言公式结果与标准数学计算误差 = 0（如 BaseRevenue=163e8, decline=20%, NetMargin=22.36%, TaxRate=15% 时结果精确）

**验收方式（自动化 + 手工）:** 单测断言公式精度；手工拖动滑块观察实时联动且无后端请求。
