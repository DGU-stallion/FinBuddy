# 04: 问财式工作台前端——时间轴 + 意图标签 + 三栏卡片 + 存证抽屉

**What to build:** 完整可操作的问财风格金融工作台。思考过程时间轴、可微调的意图标签、三栏证据卡片、点击角标滑出的右侧存证抽屉（含角标强制校验）、数据源状态指示灯。这是评委打开 URL 后直接看到并操作的全部界面（见 ADR-0002 决策 2、4 与 spec 交互决策）。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 搜索框 + 预置案例卡片 + 清空上下文按钮
- [ ] 思考过程时间轴：折叠面板，展示"正在拆解子问题""调用财务数据接口"等步进状态与耗时
- [ ] 意图标签：结构化展示（如 `[标的: 中际旭创 300308.SZ]`、`[核心命题: 大客户砍单风险]`）；删除标签自动重新分析，修改标签文本需点确认才重新分析（见 spec 交互决策）
- [ ] 三栏证据卡片：【支持证据】【反对证据】【无法验证项】三列并列展示，高密度金融排版
- [ ] 存证抽屉：点击 `[^ref_X]` 角标从右侧滑出约 380px 抽屉，三栏流式压缩；抽屉内默认展示关键字段人类可读摘要 + 可折叠完整原始 JSON，并显著标注数据源、时间戳、实时/降级状态（见 ADR-0002 决策 4）
- [ ] 角标强制校验：角标不在本轮工具返回的 refId 集合内时，渲染为灰色"引用失效"标记且不可点击（见 ADR-0002 决策 2）
- [ ] 降级状态指示灯：L2 时显式渲染 `[ ⚠️ 降级存证：外部实时接口超时，已启用权威历史存证 ]`
- [ ] 视觉规范：冷静专业灰蓝配色、红涨绿跌、高密度卡片排版，桌面端 1280px+ 优化

**验收方式（手工）:** 点击预置案例走完整链路，检查时间轴、标签、三栏、角标点击滑出抽屉、抽屉内容与降级指示灯。
